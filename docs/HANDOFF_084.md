# Garrison 0.8.4 contributor handoff

The owner continues editing the original E: workspace. This independent GitHub
checkout supplies readable source, tools, tests, editable assets, voices, recipes,
recovery stores, diagnostics, releases, contributor instructions and AI discoveries.
Normal Vietnam and other projects remain untouched.

## Measured shared data

- 151,548 source/external files; 19,771,569,771 logical bytes before storage deduplication.
- 103,896 unique chunks in 397 immutable ZIP packs; 12,397,229,653 stored payload bytes.
- Largest pack: 41,690,507 bytes, below GitHub's single-file hard limit.
- Original 0.8.4 compressed delivery: 284,922,388 bytes; its 400 MB cap remains satisfied.
- Installed Python/CUDA environments and model weights are excluded. Their pins,
  download/SDK recipes, lockfiles, publisher receipts and qualified masters remain.
- A clone also stores Git objects; allow roughly 25 GB before restoring working data.

This full-history dataset is larger than GitHub's recommended 10 GB repository size.
The initial transfer is prepared as small commits for sequential pushes, each below
its enforced 2 GiB push limit. No LFS storage or billing change was enabled.
[GitHub repository limits](https://docs.github.com/en/repositories/creating-and-managing-repositories/repository-limits).

- Current artifact hashes, 0.8.3 baseline and original owning-resource preservation

## Cleanup and retained inputs

The approved original temporary-folder cleanup removed 55,517 individually inventoried
files: 9,063,240,119 logical bytes and 22,532,325,376 allocated file bytes. Targets were

Separate generated handoff verification copies were also retired after preserving
proof/logs; those were created during this task and are not counted as pre-existing
space savings. Source art, voice masters/paid originals, installed runtime/models,
recipes, required integration inputs, failed native diagnostics, current deliveries,
recovery stores and rollbacks remain. The old temporary folder remains a live
workspace dependency and must not be deleted wholesale.

## Use and publication

Read [DEVELOPMENT.md](DEVELOPMENT.md), [DISCOVERIES.md](DISCOVERIES.md),
[AGENTS.md](../AGENTS.md) and [MILESTONE_SYNC.md](MILESTONE_SYNC.md).
Frozen receipts retain their original paths/hashes. New contributor utilities and
current guides are readable Git files; initial archived source remains its historical
snapshot. Run contributor commands from this checkout rather than an old restored
copy of its early utility scripts.

The initial source/data commits are local. `PUSH_WHEN_READY.ps1` previews the sequence;
`-Execute` performs ordinary fast-forward uploads after the owner decides to push.
It skips already uploaded batches on retry, and stops if remote changes need review.
Nothing was pushed, installed, published, billed or scheduled by this handoff.

Import, native audible quality/routing/overlap, stock effort timing, save/load and
multiplayer remain independent acceptance gates. This migration does not change the
128 approved minor speech exceptions or qualify those runtime gates.
