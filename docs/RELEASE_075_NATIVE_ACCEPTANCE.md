# Final-candidate native acceptance

Run this only on the completed candidate ZIP. Keep the frozen 0.7.4 ZIP for rollback. Source renders, native art cooks and archive hashes do not complete these tests.

1. Import the candidate in Garrison. Select this pack as both Game Mode and Tuning Pack; select China and then Vietnam. Verify fresh-match selection does not fail at blueprint lookup.
2. Compare all seven buildings at ordinary gameplay zoom and close zoom, in daylight. Check Ministry's three decorative elephants and unobstructed production route; Phổ Minh's tower/entrance; One Pillar's unchanged scale, supports, stairs and pond; Citadel walls and gate; Headquarters thatch and entrance; Garden trees, banks, bridge and service path; Foundries' furnaces, casting lane and production access.
3. Test two visibly different player colours. The native flag must change with ownership colour, remain readable and stand on its intended support. A fixed painted swatch is not a pass.
4. For each building inspect placement preview, early/mid/late construction, healthy, light/heavy damage, destruction, selectable ruins and repair/rebuild. Check that flags follow the owner's native state, with no floating leftover flag, duplicate whole building or obsolete donor geometry.
5. Exercise each building's actual production/research/age-up function and units leaving it. Costs, timings, footprint, interaction and landmark-victory accounting must match 0.7.4. Do not infer these from art alone.
6. Save and reload a match containing healthy and damaged examples, then repeat essential interaction checks. Record multiplayer separately; a solo success is not multiplayer evidence.

Record candidate ZIP/SGA hashes, game version, date, player colours, screenshots and pass/fail per building. Any missing-owner-colour, invisible-model, obstruction, native selection/repair failure or crash blocks acceptance. Report visual rubric scores independently; a technically working candidate need not meet the requested 9–10 target.
