before preparing/building. Rebuild native assets with the integration recipes and

stay native, with only the approved private pot/add-on stamp swap.

For client rollback, close AoE4 and reimport the frozen exact 0.6.1 ZIP selected
by `freeze.json`, then select its Game Mode and Tuning Pack. Verify its embedded
SGA against the hash above. Preserve 0.7.0 evidence before changing anything.

070 overlay and activation receipt. Restore only modified baseline files from
`output/release_070/source-activation/before` and remove only the nine explicitly
added private attachment-list files listed in that receipt. Compare the complete
result to the immutable baseline source inventory before any build. Do not restore
the whole normal edition or overwrite unrelated source. This document does not
automatically execute a source rollback.

After verified final packaging, inventory rebuild dependencies and remove only
explicitly identified release-owned regenerable readback/staging caches. Retain
the compact full-member/hash verification and log reclaimed bytes, then recheck
