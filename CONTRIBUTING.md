# Contributing

Read README.md, AGENTS.md and docs/PERSIA_ASSET_WORKFLOW.md first. Develop new
Persian assets in the owner's reusable Temp_before_github_push workspace. Promote
only after owner acceptance, preserving complete editable/rebuild inputs, then
document, verify, commit and push main. Use Git for tracked-source history and
output/current for final delivery/evidence. Avoid additional workspace/full-media
copies. Preserve required ignored media and immutable rebuild inputs.

Configure your installed tools, make a narrowly scoped change, and preserve all
unrelated owning resources. Include tests, an explicit changed-member policy
and the actual validation scope. docs/COMPACT_DEVELOPMENT.md describes recovery
for a genuinely new machine; it is not a requirement to restore another local
workspace before each change. Existing Ogg voices need no new voice generation.
Preserve credits hosein81 and chilly5 and existing attribution. See
docs/RIGHTS_AND_ATTRIBUTION.md.
