# Garrison 0.8.0 development baseline

0.8.0 consolidates the accepted 0.7.12 game content and its editable workspace.
The game archive is byte-identical to 0.7.12; the release version is recorded in
the Garrison package metadata. Normal Vietnam remains independent and untouched.

Start with [the development guide](docs/DEVELOPMENT_080.md) for verified source
builds, asset cooks, indexed recovery, and the workflow for editing old assets or
creating new ones. `development.json` identifies this active baseline. Existing
README/STORAGE documents and historical release tools remain frozen provenance.

Current delivery:
`output/consolidation_080/delivery/final-v1/community_civilization_pack-0.8.0.zip`.
Exact 0.7.12 and 0.7.0 rollback ZIPs and SGAs remain independently available at the
locations in the development guide. No installation or publication is included.

Keep both owned roots, their seven configured links, and `resources_071`,
`resources_080`, `consolidation_071`, and `consolidation_080` on F:. These are
required inputs and evidence. Moving files between E: and F: does not reduce the
combined storage total. Packed recovery data must not be treated as a cache.

The final consolidation report records the actual retained size and verification
gates. Temporary native builds/restores require extra working space; retire only
explicitly verified generated outputs after preserving their evidence.
